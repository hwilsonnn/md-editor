# md-editor (Markdown Editor)

Features

- Save file: `Ctrl`+`s` or by clicking the 'Download' button
- Start working on a file by dragging it into the text area
- Two modes of working
  - Edit the file by clicking on the text (this is also the default site state)
  - Preview the document by pressing the `esc` key
- Generate table of contents in preview (this will not be added to the document)
